# Care-Eyes · 护眼强制休息

> 一个原生 macOS 菜单栏护眼应用：按设定的工作间隔，全屏遮罩并强制休息指定时长。

## 为什么需要它

长时间盯屏会导致睫状肌持续紧张，引发眼干、视疲劳与注意力下降。市面上多数护眼工具只做"提醒"，一旦被你随手关掉就形同虚设。

Care-Eyes 的设计取向是：**到点就是一块全屏黑屏，你必须休息**。同时保留一条克制的紧急通道，避免关键时刻被彻底卡死。

## 功能

- 菜单栏常驻，不占用 Dock 图标
- 默认每工作 **60 分钟**，强制休息 **10 分钟**（可自定义）
- 休息时全屏遮罩，覆盖**所有显示器**与当前工作空间
- 极简大号倒计时，配随机护眼提示
- 菜单栏实时显示距下次休息的倒计时（如 `👁 59:33`）
- 可设置工作时长、休息时长、紧急退出长按秒数
- 支持暂停 / 恢复计时、手动立即休息
- 可选开机自动启动
- **紧急退出**：在遮罩底部圆点处持续按住（默认 5 秒）
- 配置仅存本机 `UserDefaults`，**不联网、不上传任何数据**

## 构建与安装

**环境要求**：macOS 11+、Swift 5.5+、Xcode Command Line Tools（或完整 Xcode）

```bash
git clone https://github.com/wuhuhu800/Care-Eyes.git
cd Care-Eyes

# 仅构建到 ./build/护眼强制休息.app
./build.sh

# 构建并安装到 /Applications
./build.sh --install
```

`build.sh` 会自动完成：release 编译 → 生成 app bundle → 从 `icon.png` 生成 `.icns` → ad-hoc 签名。

## 使用

1. 启动后屏幕顶部会短暂弹出确认浮层（约 2.4 秒自动消失）
2. 菜单栏出现闭眼图标 + 倒计时
3. 点击图标可查看状态、暂停计时、立即休息、打开设置
4. 建议开启「开机自动启动」，避免忘记开启

## 常见疑问

### 双击图标后"好像没反应"？

这是菜单栏应用的正常表现，它**不会打开主窗口**。请检查两处：

1. 屏幕顶部中央是否有短暂弹出的「护眼强制休息已启动」浮层
2. 菜单栏右侧是否有闭眼图标 + 倒计时

只要菜单栏有图标，就说明它在正常工作。应用已在运行时再次双击，会自动打开设置窗口。

### 菜单栏找不到图标？

菜单栏图标过多时可能被挤占。可按住 `Cmd` 拖动调整顺序，或在「程序坞与菜单栏」中清理其它图标腾出位置。

## 设计说明

### 为什么用全屏遮罩而不是系统锁屏

| 方案 | 优点 | 缺点 |
|---|---|---|
| 全屏遮罩（本方案） | 覆盖所有屏幕与空间；休息后无需重新输密码 | 属应用级约束，可被系统手段绕过 |
| 调用系统锁屏 | 强制性最强 | 休息期间无法看通知，每次都要输密码，体验割裂 |

护眼场景的核心诉求是"打断连续用眼"，而非"防止他人访问电脑"。因此选择遮罩方案，并保留长按紧急退出通道。

### 启动反馈为什么不依赖系统通知

早期版本使用 `NSUserNotification` / `UNUserNotificationCenter` 发送启动提示，但在通知权限被关闭的机器上，反馈会被**静默丢弃**，用户看到的就是"双击没反应"。

因此改为自绘无边框浮层（`NSPanel` + `.nonactivatingPanel`），不依赖任何可被用户关闭的系统权限，保证反馈一定可见。

## 重要限制

> **「强制」是应用级的，不是系统级锁屏。**

macOS 出于安全设计，不允许普通应用永久阻止用户通过系统级方式切换、终止或强制退出应用。用户仍可通过 `Cmd+Opt+Esc` 强制退出、`Ctrl+Cmd+Q` 锁屏等方式绕过遮罩。

这是刻意为之的取舍：本工具面向自我管理，不面向对抗性场景。

## 项目结构

```text
Care-Eyes/
├── Sources/EyeGuard/
│   ├── main.swift                    # 应用入口（@main）
│   ├── Config.swift                  # UserDefaults 配置模型
│   ├── RestWindow.swift              # 屏保级置顶窗口
│   ├── RestView.swift                # 倒计时界面 + 长按退出环
│   ├── RestScheduler.swift           # 计时调度与多屏窗口管理
│   ├── SettingsWindowController.swift # 设置面板
│   └── AppController.swift           # 菜单栏 + 启动反馈 + 开机自启
├── Tools/MakeIcon.swift              # 离屏渲染应用图标
├── Info.plist                        # LSUIElement=true（无 Dock 图标）
├── build.sh                          # 一键构建打包
└── icon.png                          # 图标源图
```
